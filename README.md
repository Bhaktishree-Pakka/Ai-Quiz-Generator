# Ai-Quiz-Generator
AI Quiz Generator is a full-stack web application that generates intelligent multiple-choice quizzes using AI. Users can enter any topic and choose a difficulty level to generate a 50-question timed quiz with explanations, score tracking, answer review, and responsive UI support. The application is built using React, Node.js, and OpenRouter API.

---

# ✨ Features

✅ AI-generated 50 quiz questions    
✅ 60 Minutes Timer  
✅ Easy / Medium / Hard Difficulty  
✅ Score Calculation  
✅ Review Answers Section  
✅ Explanation for Each Question

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Bhaktishree-Pakka/Ai-Quiz-Generator.git
```

---

## 2️⃣ Move into Project

```bash
cd Ai-Quiz-Generator
```

---

# 📦 Install Dependencies

## Root

```bash
npm install
```

## Client

```bash
cd client
npm install
```

## Server

```bash
cd ../server
npm install
```

---

# 🔑 Setup Environment Variables

Inside the `server` folder create a file named:

```bash
.env
```

Add this:

```env
OPENROUTER_API_KEY=your_openrouter_api_key
```

---

# 🌐 How to Get OpenRouter API Key

## Step 1

Go to:

https://openrouter.ai

## Step 2

Create/Login to your account.

## Step 3

Open:

https://openrouter.ai/keys

## Step 4

Create a new API key and copy it.

## Step 5

Paste it inside `.env`

---

# ▶️ Run Project

From root folder:

```bash
npm run dev
```
